# MENDELOW STUDIO - Clean Portfolio

A minimal, clean portfolio website built from scratch.

## Structure

```
/
├── new-index.html          # New home page (rename to index.html when ready)
├── about.html              # About page
├── contact.html            # Contact page
├── css/
│   └── style.css          # All styles - minimal white design
└── projects/              # Individual project pages
    ├── alto.html
    ├── custom-espresso-station.html
    └── photography.html
```

## Design Philosophy

- **Minimal & Clean**: White background, black typography
- **Simple Navigation**: Logo + About/Contact links
- **Content-First**: Focus on displaying work clearly
- **No Shopping**: Pure portfolio showcase
- **Responsive**: Works on all devices

## To Use This New Site

1. Preview `new-index.html` to see the new design
2. Add your project images to the project pages
3. Update the about page with your information
4. When ready, rename `new-index.html` to `index.html` (backup the old one first)

## Adding Project Images

In each project page, replace the placeholder divs with:
```html
<img src="../images/project-name/image.jpg" alt="Description">
```

## Colors

- Background: White (#fff)
- Text: Black (#000)
- Secondary: Gray (#666)
- Borders: Light gray (#e0e0e0)
